# Redesign v2 — implementační plán

> Spec: `docs/superpowers/specs/2026-08-06-redesign-v2-drevo.md`
> Paleta: `docs/superpowers/redesign/PALETTE-WOOD.md`
> Provádí: sonnet subagenty, jeden task = jeden subagent = jeden commit.
> Opus = review gate mezi tasky. Kód nepíše, ověřuje grepem.

**Cíl:** kompletně nový design (kostra, ne jen barvy). Dům mizí z landing page,
zůstává na `/nahled-3d`. Paleta se mění na dřevěnou.

## Globální omezení (platí pro každý task)

- Faktické údaje verbatim: telefon, e-mail, region, IČO placeholder.
- Žádná vymyšlená čísla o firmě.
- Hex hodnoty jen v `lib/palette.ts`. Výjimka `setClearColor(0x000000, 0)` (D-022).
- Žádné pomlčky (— –) v uživatelsky viditelném textu; reformulovat, ne nahrazovat
  dvojtečkou (D-027).
- Kontrast dle PALETTE-WOOD.md včetně variant s průhledností.
- Každý commit: `npm run typecheck` && `npm run lint` && `npm run build`.
- `npm run dev` v tomto prostředí není spolehlivý signál (viz HANDOFF.md).

## T1 — Paleta a písma

**Soubory:** `lib/palette.ts`, `tailwind.config.ts`, `app/globals.css`,
`app/[locale]/layout.tsx`, `components/house3d/config.ts`, plus mechanické
přejmenování tokenů napříč `app/` a `components/`.

- Přepsat `lib/palette.ts` na strukturu `paper / timber / oak / ember`
  s hodnotami z PALETTE-WOOD.md. Nechat `HOUSE3D_FACE`.
- `tailwind.config.ts`: mapovat nové tokeny, přidat `fontFamily.display` →
  `var(--font-display)`, `body` → `var(--font-body)`, `mono` → `var(--font-mono)`.
- Načíst **Fraunces** (display) přes `next/font/google`, ponechat Archivo (body)
  a IBM Plex Mono. Všechny tři proměnné na `<html>`. **Ověřit, že každá
  `var(--font-*)`, kterou Tailwind konzumuje, je skutečně definovaná** (D-025).
- Ověřit českou diakritiku Fraunces inspekcí cmap staženého `.ttf` (fontTools).
- Přejmenovat napříč repem `slate→timber`, `steel→oak`, `patina→ember`
  (a jejich `-soft`/`-dim` varianty) tak, aby build zůstal zelený.
- Zvýšit každou průhlednou variantu (`/N`) na minimum z PALETTE-WOOD.md.

**Hotovo když:** build zelený, `grep -rn -E '#[0-9a-fA-F]{6}|rgba?\(' app components lib`
vrací jen `lib/palette.ts`, žádný výskyt `slate|steel|patina` mimo dokumentaci.

## T2 — Hlavička a patička

**Soubory:** `components/layout/Header.tsx`, `Footer.tsx`, `Logo.tsx`,
`LanguageSwitcher.tsx`.

- Wordmark viditelný okamžitě a vždy, i na homepage nad ohybem.
- Žádné vyplněné tlačítko v hlavičce; CTA je textový odkaz s podtržením.
- Sticky zúžení po odscrollování (menší wordmark, hairline, `paper/90` + blur).

- Patička: úzký `timber` pás, wordmark, nav, IČO, copyright.

## T4 — Homepage: realizace, postup, o nás, kontakt

**Soubory:** `components/sections/ProjectsPreview.tsx`, nový `Process.tsx`,
`AboutSection.tsx`, `ContactSection.tsx`, `components/ui/ImageFrame.tsx`,
`messages/cs.json`, `messages/en.json`.

- Postup: `paper.dim`, čtyři kroky, průběžná vlasová linka, mono číslice v `ember`.

## T7 — Audit

- Přeměřit **všechny** skutečně použité dvojice barva/pozadí včetně `/N` variant.
- Sweep pomlček ve všech uživatelsky viditelných řetězcích včetně
  `alt`/`aria-label` skládaných v šablonových literálech (D-028).
- Ověřit, že žádná `var(--font-*)` ani `theme('colors.*')` neodkazuje na neexistující
  hodnotu.
- Grepy: hex mimo palette, staré názvy tokenů, mrtvé importy.
